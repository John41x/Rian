# Spec 05: Synthetic Telemetry & GIS Simulation Harness

## 1. Module Overview
The **Simulation & Validation Harness** enables multi-agent development and continuous integration without physical Reolink hardware, cellular SIM subscriptions, or live USGS elevation downloads.

It provides:
1. **Synthetic GIS & Terrain Generator:** Creates realistic DEM elevation rasters, slope surfaces, and topological road graphs.
2. **Mock Camera Telemetry Emitter:** Emulates Reolink Go Plus outbound SMTP clients by sending valid MIME snapshot emails over SMTP to port 2525.
3. **Kinematic Scenario Runner:** Simulates moving targets (vehicles, pedestrians, livestock) traversing the property, triggering virtual camera tripwires, and validating end-to-end tactical response directives.

## 3. Synthetic GIS Generator (`tools/synthetic_gis.py`)

### 3.1 Terrain Surface Generation
- Generates a $1000 \times 1000$ grid representing a $10\text{km} \times 10\text{km}$ estate at $10\text{m}$ resolution (EPSG:3857 / EPSG:4326).
- Synthetic elevation model constructed using multi-frequency Perlin/Simplex noise or Gaussian hill functions:
  $$Z(x, y) = 400 + 150 \sin(0.001 x) \cos(0.001 y) + 80 \exp\left(-\frac{(x - 5000)^2 + (y - 5000)^2}{2 \cdot 1200^2}\right)$$
- Computes slope raster $\theta = \arctan(\sqrt{(\partial z/\partial x)^2 + (\partial z/\partial y)^2})$.
- Exports to `data/rasters/synthetic_dem.tif` or loads directly into PostGIS `elevation_rasters`.

### 3.2 Topological Road Network
- Generates a connected graph with 4 perimeter exit gates and 2 interior intersecting ranch roads.
- Seeds `property_network_edges` and `strategic_chokepoints`.
- Places 6 virtual `sensor_nodes` at road intersections and gates.

## 4. Mock Camera Telemetry Emitter (`tools/mock_camera.py`)

### 4.1 Reolink MIME Emulation
The mock emitter crafts an authentic email matching the exact MIME multipart headers generated by Reolink cellular cameras:
```python
import smtplib
from email.message import EmailMessage

def send_mock_camera_detection(
    smtp_host: str = "127.0.0.1",
    smtp_port: int = 2525,
    camera_email: str = "cam-gate-north@ranch.domain",
    image_path: str = "tests/data/sample_truck.jpg",
    subject: str = "Motion detection alert from Reolink Go Plus"
):
    msg = EmailMessage()
    msg["Subject"] = subject
    msg["From"] = camera_email
    msg["To"] = "ingest@rian.internal"
    msg.set_content("A motion detection event has occurred at Gate North.")
    
    with open(image_path, "rb") as f:
        image_bytes = f.read()
        
    msg.add_attachment(
        image_bytes,
        maintype="image",
        subtype="jpeg",
        filename="snapshot.jpg"
    )
    
    with smtplib.SMTP(smtp_host, smtp_port) as client:
        client.send_message(msg)
```

## 5. Automated Validation Scenarios

### Scenario 1: Vehicle Intrusion along Main Road (`vehicle_intrusion`)
1. **Target:** Unauthorized `truck` enters via North Gate at $t = 0$.
2. **Action:** Cam 1 triggers and emits snapshot email.
3. **Engine Evaluation:**
   - Ingestion daemon parses MIME and YOLO confirms `truck` (conf $\ge 0.85$).
   - Kinematic engine creates track `TRK-001`.
   - Isochrone expands confined to the road corridor (infinite friction off-road).
   - Tactical solver identifies South Exit Gate as the intercept point with 7-minute lead time.
   - Twilio alert directive generated.
4. **Acceptance:** Assert `tactical_directives` table contains an entry with `tactical_margin_seconds >= 180.0`.

### Scenario 2: Pedestrian Intrusion across Rough Terrain (`pedestrian_hike`)
1. **Target:** Trespassing `person` crosses fence at East Boundary at $t = 0$.
2. **Action:** Cam 4 triggers and emits snapshot.
3. **Engine Evaluation:**
   - YOLO confirms `person` (conf $\ge 0.75$).
   - Kinematic engine initializes track `TRK-002`.
   - Isochrone expands using Tobler's Hiking Function, slowing uphill and flattening against a steep $40^\circ$ canyon wall.
4. **Acceptance:** Isochrone polygon boundary matches expected anisotropic travel time within 10% error margin.

### Scenario 3: Spatiotemporal Gating Rejection (`multi_target_gating`)
1. **Target 1:** Cam 1 detects `person` at $t = 0$.
2. **Target 2:** Cam 5 (located 4,000 meters away) detects `person` at $t = 30\text{ seconds}$.
3. **Engine Evaluation:**
   - Velocity required: $4000\text{m} / 30\text{s} = 133\text{ m/s} \gg 4.0\text{ m/s}$ ($v_{max}$ for person).
   - Kinematic gating envelope rejects association with Track 1.
   - System initializes independent Track 2.
4. **Acceptance:** Exactly 2 distinct active tracks exist in `entity_tracks`.

## 6. CLI Usage

```bash
# 1. Initialize local test database and seed synthetic GIS & camera nodes
python -m tools.simulator init-db

# 2. Run a specific end-to-end integration scenario
python -m tools.simulator run-scenario --name vehicle_intrusion

# 3. Fire a single mock camera snapshot trigger
python -m tools.simulator emit --camera cam-gate-north --target person
```
